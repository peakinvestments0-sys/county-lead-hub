# Florida Lead Hub Helper - Chrome Extension

This extension enables **1-Click Free Skip Trace Syncing** from TruePeopleSearch directly into your Florida Lead Hub dashboard.

## 🚀 How to Install in Google Chrome (Takes 10 Seconds)

1. Open **Google Chrome** and type in the address bar:
   ```
   chrome://extensions
   ```
2. In the top-right corner, turn ON **"Developer mode"** (toggle switch).
3. In the top-left corner, click **"Load unpacked"**.
4. Browse to and select this folder:
   ```
   C:\Projects\Apps\Pinellas-county-app\chrome_extension
   ```
5. Done! The **Florida Lead Hub Helper** icon will appear in your Chrome toolbar.

---

## ⚡ How It Works

1. In **Florida Lead Hub**, click **`📞 Free Trace`** on any lead.
2. TruePeopleSearch opens with the person's profile.
3. You will see a banner at the top: `⚡ Florida Lead Hub Connected`.
4. Next to the mobile numbers, click **`[ 🚀 Push to Lead Hub ]`**.
5. The phone number immediately syncs to your dashboard in the background!
